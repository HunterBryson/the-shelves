# Imports

*For the AI.* When your person pastes something big for you to know (their old AI's memory, a document, notes), you save it here word for word as `<date>-<what it is>.md`, then file everything in it onto the map in the same turn. Put a line at the top of the saved file: `Filed <date> into: human.md, money/money.md, ...`. A file here without that line hasn't been filed yet.

Your person never puts files here or sorts anything. If they ever drop a file in this folder themselves, read it and file it the same way.
